# HCR2 Setups Guide

A web based app that acts as a 'hub' for all of the different time attack setups in the mobile game HCR2. It is designed to help players find, create, delete, and update setups all in one place.


## How to run the app

Run these commands in a terminal:

1. Clone the repository:
   
   git clone https://github.com/Number22313/HCR2-Setups-Guide.git

2. Navigate to the repository folder:
   
   cd HCR2-Setups-Guide

3. Activate the Virtual Environment:
   
   Linux/MacOS:
   source venv/bin/activate

   Windows:
   venv\Scripts\activate

4. Install the required packages to run:
   
   python -m pip install -r requirements.txt

5. Run the app:
   
   python app.py

The app should now be running and you can open it in any browser by going to: http://127.0.0.1:5000/
